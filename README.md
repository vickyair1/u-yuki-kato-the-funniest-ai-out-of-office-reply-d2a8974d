# The Funniest AI Out-of-Office Reply

One line, 90 characters, a two-beat escalation — the auto-reply has an
auto-reply, and neither of them is coming back:

> Out of office until Monday. My auto-reply has an auto-reply. Neither of us is coming back.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline) and prints it
to stdout. Stdlib only, deterministic.
